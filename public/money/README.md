# お金管理 — 新しい財務管理アプリ

「次の支払い・貯金・NISA・生活防衛ラインを確保したあと、今いくら使ってよいか」を最初に表示する、スマートフォン中心のPWAです。

## 現在の実装

- ホーム: 期限までに使える総額、1日あたりの目安、内訳、次の予定
- 予定: 支払い・収入・貯金・NISA・振込の登録、確定、編集、削除
- 記録: 確定済みの取引と実質負担の集計
- 口座: 基準口座・自由利用口座・貯金口座・投資口座を明示
- 設定: 生活防衛ライン、JSONバックアップ、リセット
- 追加: 右下の追加ボタンから支払い・収入・貯金・NISA・振込・クレジットカード・口座を選択
- 振込: 自分の口座間の移動と、他人口座への振込を区別
- カード: カード名・引落口座・締め日・支払日を登録し、支払い時にカード別で選択
- カード予定日: 選んだカードの締め日・支払日から次回引落予定日を自動設定（手動変更可能）
- 請求見込み: 未確定のカード支払いをカード別・引落日別に集計し、合計と内訳をホームに表示
- 給与見込み: 時給と勤務時間から、勤務済み・勤務予定・次回給与を計算してホームに表示
- 勤務記録: 日付、勤務時間、勤務済み／予定、その日だけの時給変更、メモを保存・編集・削除
- 給与設定: 時給、締め日、給料日、支給月、見込み額を「今使える金額」に含めるかを設定
- 試算: 「使ったらどうなる？」で、入力額を使ったあとの総額と1日あたりを保存せず確認
- 構成: 日付計算と試算を `finance-engine.js` の純粋関数へ分離
- アイコン: 文字を使わない深緑・白・赤のSVGアイコンをPWAに設定
- 保存: 端末のlocalStorage（JSONの書き出し・読み込み対応）
- デモ: `index.html?demo=1` でサンプルデータを表示
- 文言: [文言見直しリスト](./文言見直しリスト.md) に現在の表現と変更候補を整理

## 計算の扱い

元アプリの締め日、当座未決済、余力、実質負担の計算契約を残し、その上に「自由利用口座・期限内収入・未実行の貯金・未実行のNISA」を加えています。詳細は [SOL_DESIGN.md](./SOL_DESIGN.md) を参照してください。

## 起動

静的ファイルなので、GitHub Pagesまたはローカルの静的サーバーで起動できます。`file://` 直開きでも表示できますが、PWAのインストール確認にはHTTP環境を使ってください。
