# お金管理・手書き案のUI試作

参照: 本チャット添付「ノート_261109_013642.pdf」1〜2ページ（3ページ目は白紙）。

## 今回作成した範囲

- スマホのOSステータスバーを覆わない。疑似時計・電池アイコンは作らず、safe-areaを考慮。
- Google Fonts Kiwi Maru。本文400、項目・見出し500。
- 左スライドインのモーダルサイドバー。メイン9項目、サブ5項目。下部の画面移動タブなし。
- ホーム内2ページのカルーセル。横スワイプ、ページ選択ボタン、矢印キーで移動。
- 1ページ目: 日付付き残額、計算内訳、確認事項。予定収入はこの額に足さない。
- 2ページ目: 予定給与・仕送りを含めた口座残高の推移アニメーションと表。
- 通常・不足・データなし・読み込み中・オフライン・エラー・保存完了の表示切替。
- 背景タップ・閉じる・Escape、フォーカス管理、非表示スライドの操作防止、動きを減らす設定。

## 分離と未完成の範囲

このフォルダは試作専用。Firebase/Gmail/本番計算に接続せず、localStorageも書き換えず、Service Workerも登録しない。
金額は架空。現在残高180,000円−11/10カード100,000円−11/15まで生活費20,000円−予備10,000円=50,000円。
不足状態だけ開始残高60,000円。他の予定は同じ。給与78,000円・仕送り55,000円は予測のみに加算。
表は実残高予測なので予備額を支出にしない。元のアプリの計算式は変更していない。
期間・実際の計算条件・配色の最終承認は別途行う。

別メニューの画面と確認項目の入力・保存フォームは未作成と明示し、ダミー保存は行わない。
今回すべての業務画面が完成したという意味ではない。状態の網羅は画面を追加するごとに行う。
本番への切替・公開・既存メニューの置換は行わない。

## ローカル表示

プロジェクトのローカルサーバーで `/money/ui-prototype/index.html` を開く。
Google Fontsは通信がある場合に取得。通信できない場合は端末の代替フォント。

自動検査は `node public/money/ui-prototype/check-ui.cjs`。ローカル静的サーバーと隔離ブラウザーを起動し、実ユーザーのブラウザー・データは操作しない。
