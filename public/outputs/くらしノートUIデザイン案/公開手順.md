# 今回の変更をプレビューへ進める手順

選択したM5・N1・R1を実装し、ローカルの操作・表示・ビルド確認まで終わっています。
次の手作業は、**GitHub Desktopで作業ブランチを公開すること**です。

## 1. 今回の作業フォルダーを開く

GitHub Desktopを開き、上のメニューから **File → Add local repository…** を選びます。
Local pathの欄に、次のフォルダーを指定してください。

```text
C:\Users\humal\Documents\Codex\2026-06-23\new-chat\work\nakami-memo-publish\.claude\worktrees\instructions-needed-152678
```

**Add repository**を押します。すでにこのフォルダーを開いている場合、この操作は不要です。

## 2. ブランチ名と公開ボタンを確認する

上部の **Current branch** が次の名前になっていることを確認します。

```text
codex/kurashi-ui-themes
```

右側の **Publish branch** を押してください。すでに公開されている場合は **Push origin** と表示されます。
コミットは済ませてあるので、新しくコミットを作る必要はありません。

## 3. 公開が終わったら

このチャットで「公開しました」と伝えてください。その後、プレビューをスマートフォンで確認する段階に進みます。
本番への反映は、その確認後です。

作業ルールの「実機確認が要る変更は、Vercelプレビューで確認してからマージする」に従うため、mainへ先にマージしていません。
Firebaseのルール公開や設定変更、アプリの再インストールは今回の変更では必要ありません。
