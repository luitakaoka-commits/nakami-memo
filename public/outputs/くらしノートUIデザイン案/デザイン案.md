# くらしノート — 15のUIデザイン案

「お金管理は金融感のある重厚な雰囲気」「なかみメモは家らしくワクワクする仕掛け」「つくりおきノートは料理らしく」というご要望に合わせた、操作できる比較用の見本です。

## 見方

1. `index.html` をブラウザで開きます。
2. 上部の「お金管理」「なかみメモ」「つくりおき」を押すと、それぞれ5案が表示されます。
3. 見本の下部にある色付きボタンで、その案の仕掛けを試せます。見本内の下のメニューも操作できます。
4. 「大きく見る」で、説明と少し大きな見本を開きます。
5. 気に入った案で「この案を候補に」を押します。各アプリで1案ずつ選べます。
6. ページ下の「選んだ案をコピー」を押し、チャットに貼り付けてください。

候補は使用したブラウザに保存されます。ブラウザのデータを消すと候補も消えます。保存を禁止している環境でも、その場での比較はできます。

## 共通の考え方

- 見本の金額、品物、レシピ、日付はすべて架空です。
- 実際のアプリ、Firebase、在庫、給与、レシートは変更していません。
- 動きは操作した部分を中心に短く出します。小さな雲や湯気などの背景演出も試せます。
- 上部の「動き：オン」で動きを止められます。端末の「視差効果を減らす」などの設定にも従います。
- 文字は日本語本文の読みやすさを保ち、見出しで明朝・丸ゴシック・手書き風を使い分けます。
- Google Fontsを利用できると指定したフォントで表示します。オフラインや通信制限時は端末の日本語フォントに切り替わります。
- 色・見出しの書体・ギミックは別々の案から組み合わせられます。
- 採用案が決まったら、既存機能、共有、認証、3アプリの切り替え、PWAの識別を維持して各画面へ展開します。
- このページは画面の方向性を比較するものです。本番の全画面や通信・保存処理の実装は含みません。
