# お金管理・手書き案のUI試作

参照: 本チャット添付「ノート_261109_013642.pdf」1〜2ページ（3ページ目は白紙）。

## 今回作成した範囲

- スマホのOSステータスバーを覆わない。疑似時計・電池アイコンは作らず、safe-areaを考慮。
- Google Fonts Kiwi Maru。本文400、項目・見出し500。
- 左スライドインのモーダルサイドバー。メイン8項目、サブ5項目。下部の画面移動タブなし。
- 資金繰り・試算が起動画面。支払いの見通しとメール確認はサイドバーから開く。サイドメニューのアイコンは添付の downloadfile.PDF を参照。
- 資金繰り・試算は日付付き残額、計算内訳、確認事項を表示。
- 支払いの見通し: 予定給与・仕送りを含めた口座残高のグラフと表。
- 見通しグラフは棒グラフ。0円を基準に正残高は青で上向き、負残高は赤で下向き。縦目盛りは万円単位（0のみ0円）、金額範囲に合わせて読みやすい間隔にする。
- 通常・不足・データなし・読み込み中・オフライン・エラー・保存完了の表示切替。
- 背景タップ・閉じる・Escape、フォーカス管理、非表示画面の操作防止、動きを減らす設定。

## 文言方針（本人の追加指示）

画面の文章は必要最小限。操作の説明・予防的な注意書き・計算の一般論・開発上の補足説明を自動追加しない。
本人が削除指定した文言は、ダイアログなどへ移して残すこともしない。本人の差し替え文言が届いたらそれを使用する。
承認済みの注意事項を、金額の内訳や該当する操作画面に表示する。枠付きの注意は丸い「！」を添え、ホバー時に枠と背景を変える。

### 注意事項の前提

- ホーム・資金繰りの額は予定給与・仕送りを加算していない。見通しの表・グラフは加算している。
- 残額には予備額を確保する。見通しの口座残高には予備額を支出として計上しない。
- 未登録の支払いは計算対象外。予定収入や見込み請求の変更によって予測残高は変わる。
- 試作は架空データ。入力・保存・メール接続は未実装。

- メール確認はサンプルデータで未取り込み、取り込み済み、無視の順に横スワイプ。再入場時は未取り込み。フォーム操作は試作内の状態だけを変更する。

- メニューのヘッダーを画面上部に固定。予定は月間カレンダーと選択日の一覧で表示し、サンプル予定の追加・編集・削除・確定を操作できる。メールと予定の操作結果はトーストで表示。

## 分離と未完成の範囲

このフォルダは試作専用。Firebase/Gmail/本番計算に接続せず、localStorageも書き換えず、Service Workerも登録しない。
金額は架空。初期の試算は残高180,000円から11/10の引落100,000円、11/15の生活費20,000円、12/10の引落120,000円、予備額10,000円を引き、70,000円の不足。
不足状態だけ開始残高60,000円。他の予定は同じ。給与78,000円・仕送り55,000円は予測のみに加算。
表は実残高予測なので予備額を支出にしない。元のアプリの計算式は変更していない。
期間・実際の計算条件・配色の最終承認は別途行う。

別メニューの画面と確認項目の入力・保存フォームは未作成と明示し、ダミー保存は行わない。
今回すべての業務画面が完成したという意味ではない。状態の網羅は画面を追加するごとに行う。
本番への切替・公開・既存メニューの置換は行わない。

## ローカル表示

プロジェクトのローカルサーバーで `/money/ui-prototype/index.html` を開く。
Google Fontsは通信がある場合に取得。通信できない場合は端末の代替フォント。

自動検査は `node public/money/ui-prototype/check-ui.cjs`。ローカル静的サーバーと隔離ブラウザーを起動し、実ユーザーのブラウザー・データは操作しない。
